# Phase 6 test: Exams, Results, Report Card

1. Naya `Code.gs` Apps Script mein paste karo, Save. **Deploy → Manage deployments → ✏️ Edit → Version: New version → Deploy.** (setup dobara nahi chalana)
2. **Admin → Exams:** "+ Create exam" → naam (Unit Test 1), class (ya "Saari classes"), date, max marks. Ban jaata hai.
3. **Teacher → Marks Entry:** exam chuno, subject chuno, marks bharo, Save. (Exam ab dropdown mein dikhega.)
4. **Admin → Exams → Results:** poori class ka sheet (subject-wise marks, total, %, grade, rank, Pass/Fail). "Download CSV" aur "Print all report cards" bhi.
5. **Report card:** sheet mein "Report card" link → naya tab → "Print / Save as PDF".
6. **Class teacher login → Report Card (Class Results)** menu: sirf apni class ka sheet. Doosre teacher ko poora result nahi dikhta.
7. **Student login → Report Card:** apne marks, grade, rank + "Report card (PDF / Print)" link.
8. Rules: marks wale exam ka max kam nahi ho sakta aur woh delete nahi hota. Marks galat bhare to dobara save karo (latest jeetta hai).

Grade: A+ 90+, A 80+, B+ 70+, B 60+, C 50+, D 40+, E 33+, F neeche. Pass = har subject mein 33%+.
