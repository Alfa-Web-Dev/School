# Phase 10 test: Certificates + ID cards

1. Naya `Code.gs` paste, Save. **Deploy → Manage deployments → ✏️ Edit → New version → Deploy.**
2. **Admin → Certificates:** student chuno, type chuno (Bonafide / TC / Character), zaroori detail bharo, **Generate**. Certificate dikhega, **Print / Save as PDF** se PDF.
3. Har certificate ka serial number (BON/2026/0001 jaisa) apne aap banta hai aur Activity Log mein record hota hai.
4. TC inactive / passed-out student ke liye bhi ban sakta hai (student list mein status likha aata hai).
5. **ID cards:** class chuno → Make ID cards → Print. QR mein student ID hai. (Photo abhi nahi, baad mein jodenge.)
