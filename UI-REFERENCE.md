# UI direction (final polish step) — user ke reference screenshots se

Common style: mobile-first, soft & friendly "edu app" look.
- Bade rounded cards (radius 24-32px), pastel rang (mint, peach, lavender, pink, yellow) + ek dark/black accent (active tab, buttons).
- Light background (white / soft gradient), bold bade headings ("Your activities today"), chhota grey subtext.
- Floating pill bottom navigation (mobile), active tab highlighted; circular icon buttons (back, bell, calendar).
- Home: greeting + avatar + bell, horizontal date strip (week), "Today class" card, timeline list.
- Progress/analytics: donut chart, rounded bar chart, stat tiles (big number + arrow button), % chips.
- Lists: pill-shaped rows with icon circle, subject, date/time chips (Last lessons, Past exams with Result tag).
- Onboarding/login: big friendly illustration/photo + heading + round arrow button.
- Cards with arrow-button (top-right) to open details.

Mapping: Student home = greeting + date strip + today's periods + attendance donut + fee/result tiles; Timetable = week strip + timeline; Results = Past-exams style list with grade chips; Notes = colorful subject cards; Admin dashboard = stat tiles + charts.
Rule: school colour (CFG.color) theme ho, pastel palette uske saath. Dark mode optional.
